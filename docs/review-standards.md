## v0.3.0 增量

Three.js MIT 只喺啟動 3D 場景時載入，固定版本及納入 npm audit。球面紋理由公有領域圖資預計算，唔拉遠端瓦片。只開一個 renderer，退出場景釋放該場景幾何與材質；3D 不可用時保留 2D 導航。S7 artifact 仍低於 5 MB。3D 尚未以手機真機測幀率或耗電。

## v0.4.0 增量

- 地區資料、SVG 後備投影同 Three.js 地點使用同一純資料快照；可按 [Credits](../CREDITS.md) 原樣重建，無遠端載旗或抓訪客位置。
- 清單、到達頁同選定地點都有文字／實數，唔單靠色。地區搜尋唔重繪地球或搶走輸入焦點；可用鍵盤、減少動態偏好及 2D 後備完成走訪同打開展示。

## v0.4.1 增量

官方組織標誌只用使用者主動開啟嘅來源連結；不放寬圖片 CSP，未核實嘅會旗唔出旗圖。匯入嚴格限制 WOSM 會徽縮圖路徑，會旗另以明列嘅人工核對來源維護。

## v0.5.0 增量

- 本機 IndexedDB 保留舊資料庫及 object store，v1 備份仍可匯入；v2 驗證限定三個藏品類型。屋簡介轉義、屋身／屋頂限定枚舉、自選色只接受六位 hex。
- 站點 Permissions Policy 開放同源相機，繼續封麥克風；用戶撳掣後先申請相機。拍照、取消、關閉對話或離開網站時停止影像串流；瀏覽器拒絕時能選擇系統拍照或檔案。構建及 Chromium 假相機核對通過，未測實體手機系統相機。

## v0.6.0 增量

- 社交連結只接受無帳密嘅 HTTPS 網址，確認前只係表單草稿；外連無預載、使用 `noopener noreferrer`。未經正式發佈或後端驗權，不將本機訪客預覽描述為互聯網公開屋。
- 未簽到唔記訪客資料；不取 IP、定位或裝置指紋，不要求真名。名單不顯示喺訪客預覽，但同瀏覽器工作台可查閱，唔係跨使用者私隱機制。兩種日期分開儲存，不用訪客活動冒充屋主活動。
