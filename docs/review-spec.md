# Spec · BadgeHouse v0.2.0

| 用戶要求 | 結果 |
|---|---|
| 「參考真理倉內的指引去設計 UI」 | Scout Field 落到導航、編輯及顏色；設計驗收記錄三寬與六項 critique。 |
| 「去參考看看 GitHub 有沒有類似作品」 | WorkAdventure、Tiled、World Atlas 經固定 commit 對照，記錄取捨。除公有領域地圖資料外，冇搬入作品程式碼／美術。 |
| 「用真理倉的審核和建構方式」 | 來源預檢；起手文件；版號產物、測試、guard、final check、preflight、兩軸獨立審核。 |
| 「有個人仔走到地球上嗰個地區，再揀屋行入去」 | 實際步行兩次；可直開示範地區／屋，亦有 reduced-motion 路線。三區六屋係示範資料。 |
| 「每個人可以自己設計自己嘅屋」 | 可改屋名、配色、屋頂、展示傢俬並儲存本機；未有自由拖放或真實公開發佈。 |

**最弱項**：仍未有跨裝置身份、屋主發佈／真屋資料、R2、邀請及信箱，不能當正式成品；直連政策唔變，將來不公開屋仍需後端驗權。

## v0.3.0 · 「我想要 3D」

地球係可拖動球體；街坊、屋外、室內係有座標／透視角度／燈光嘅 WebGL 模型。地方與門口有實際角色路徑，設計表會改模型。支援拖動轉視角，唔係可自由走動的多人 3D 世界。公開發佈、帳號及交換仍未接駁。

## v0.4.1 · 認識當地童軍

176 個到訪頁（有屋／0 屋）都可讀組織名及開官方名錄。保留地區旗識別，會徽與會旗各有獨立連結／未核實狀態。會旗先提供香港、日本、加拿大三個已核對的原始來源，未把其他會徽當成會旗，亦未在 BadgeHouse 重製旗圖。

## v0.5.0 · 屋主設計、收藏及拍照

- 280 字屋主簡介，屋名和簡介作純文字，本機保存。四款屋身和六款屋頂各自揀，12 種色板另可各自自訂屋頂、外牆同門窗邊。自訂屋身係外觀，雙層屋未開額外樓層。
- 本機屋嘅 3D／2D 擺設與文字連結對應三類收藏。每類可新增、查找、修改及刪除，舊未分類藏品列入章簿。
- 用相機拍一張直接附到表單，預覽後再確認儲存；同一表單保留選擇檔案。未有雲端上傳或跨裝置發佈。

## v0.6.0 · 書籤、社交與到訪

- 自願留低 Instagram、Facebook、其他 HTTPS 社交連結。加入或改動前必須彈出可公開見到、複製或轉發嘅警告；取消唔儲存，清空再儲存即移除連結。訪客預覽唔展示私人藏品、筆記或簽到名單。
- 入屋可加／移除書籤，再喺主導覽打開書籤返去。示範屋無假活動日期。
- 本機訪客預覽可自願簽到，用未驗證暱稱或匿名；屋主看暱稱及到訪時間，每部裝置保留最多 60 筆，亦可清除。屋主最近返屋只表示開過工作台；屋資料最近更新指有設計／公開資料改動，不代表私人藏品有更新。跨裝置身份、發佈、訪客紀錄仍未接駁。
