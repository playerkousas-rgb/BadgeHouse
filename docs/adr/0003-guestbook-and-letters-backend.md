# ADR 0003：留言同私人信上跨裝置後端

**Status**: accepted（2026-11-19 用戶選定）

用戶要求人參觀收藏，並可以向屋主留言同寫信。SCOPE 原本將「非即時信箱」放第三段，但用戶決定留言與私人信提前至第二段一併做。已採納：後端用 **Supabase**（身份、留言同信件 metadata）加 **R2**（展示相）。留言分兩類：訪客公開留言免登入，只需暱稱，設限速，並可檢舉；私人信必須登入，以減少濫用。

**Considered Options**
- 只保留本機瀏覽器：無法跨裝置，屋主收唔到留言，否決。
- Vercel 內建儲存：Vercel 連接器目前只提供部署、專案同環境變數管理，未見資料庫或檔案儲存 API，未作評估完成，暫不採用。

**Consequences**
- 需要另開 Supabase 與 R2 帳號；Secret（service key、R2 憑證）只放伺服器端或 Vercel 環境變數，不放前端。
- 公開留言必須有限速、檢舉及封鎖；私人信要登入，所以第二段要同時交付登入流程。
- SCOPE 第二、三段已按此修訂。
