# ADR 0001：本機完整章簿，網上展示副本

**已採納（產品方向）；後台尚未實作。**

- 版本一採用靜態 SPA、瀏覽器 IndexedDB；備份 JSON v1 包含縮放後嘅本機相片及備註，並非保證保留原始照片。建議另外保存原圖。正式站保持穩定網域，換域前提醒匯出。
- 正式站可用 Cloudflare Pages 靜態部署，無入口白名單。Supabase 負責身份同 metadata、R2 放展示相，唔經 Supabase 逐張轉送。登入方式（例如 Google OAuth）及實際專案待確認。
- 不公開展示相必須存於私人區域，後端檢查屋設定／邀請後才提供短效讀取權。公開相快取要驗證下架，以及公開轉不公開時清掉舊網址／快取嘅時間界線。連結撤銷不能回收截圖或已下載副本。
- 容量係設計目標唔係固定屋主上限：實測真章圖片、500 件入簿及逐頁載入。上傳前限制大小與頻率，監察月度儲存、實際讀取及超額費用；免費額度唔係自動停用閘。到需要資金先接洽支持。
