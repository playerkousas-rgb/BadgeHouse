# BadgeHouse v0.2.0 · 設計驗收

**類型**：探索 app 唔係 landing page。**主張＋證據**：由地球出發探屋（可撳地點嘅真海岸線、方向路線同角色定位）；到街坊要揀門（兩間不同屋、角色真係走）；屋主可自己設計（屋外及室內預覽、可保存設定）。風格與對比見 [DESIGN](../DESIGN.md)。

Inventory 10 項：海岸線、羅盤、地區點、步行角色、路線、到達狀態、街坊門口、展品傢俬、屋外預覽、屋設計控制。

## ROUND 1–2

以 Chromium 實拍 390／768／1440，另外檢視街坊同屋設計。六項：

1. **Focus（1／5 秒）**：開首頁只有一個主要動作「行去一個地區」。冇行銷 hero 或模擬用戶數字。
2. **Squint**：世界地圖主體、右方窄路線欄；小屏改全寬圖＋三個地區掣，唔硬縮成雙欄。
3. **遮 logo**：仍見小童軍、章屋、探屋路線及章簿傢俬，唔係一般地圖 dashboard。
4. **Edges**：街坊可直接撳屋門，亦可用場景下方一對一地點掣；鍵盤 focus 有可見輪廓。
5. **Phone**：避免依賴細小 SVG 文字；390 第一屏有手機版地區掣。初輪 390／768 CJK 字體有載入方格，改本地 WOFF2 預載並重新取圖。
6. **Substance**：舊版場景卡片唔等於探屋，已改到達／街坊／入屋三步；室內加入可按展示傢俬。樣板屋、未發佈、本機模式有明確標示。

改善前／後主要三項：**卡片目錄 → 世界場景；靜態跳轉 → 兩段步行並有 reduced-motion；縮小點位 → 手機原生按鈕及字體預載**。主觀 40/30/20/10：33+24+16+7=80/100，未代替用戶驗收。未做實機 iOS／Android 或聲稱 60fps。

## v0.3.0 · 3D 望圖與改動

- **場景層級**：主體係拖動嘅球體，行路狀態仍保留文字；街坊相機先見門前小路，屋內用剖面俾人見到立體傢俬。390／768／1440 Chromium WebGL 截圖；另望加拿大街坊、室內及平頂編輯預覽。
- **ROUND 1 → 2**：地球背光令角色太暗／細，改觀察方向照明同加大角色；室內地台有截角，放鬆正交相機；手機將球體框由橫圖改近方形，保留大地區掣。其他六項沿用上文檢視，未將軟體 Chromium 當手機硬體效能測試。
- **操作**：實測拖動地球、出發到加拿大、行到屋內、儲存設計及重新載入。手動 2D 切換及強制禁用 WebGL 均可繼續探屋。未測實機 GPU 幀率。

## v0.4.0 · 地區及屋內導覽

- 1440：地球仍係主體，右欄先見有屋地區，篩選／搜尋後留住「而家準備去邊」同下一步。
- 768／390：場景與地區清單逐塊排，清單限高獨立捲動，長地名可換行，旗幟及數字固定；驗證無橫向溢出。
- 屋內留一個視角俾模型；收藏按鈕唔取代 3D 實物，係鍵盤和 2D 可用嘅入口。空地區明示 0，不顯示不可用門牌。
- Chromium（軟體 WebGL）試走法國 0 屋、日本及加拿大示範街坊、室內三類，同本機設計儲存、切換 2D／WebGL 不可用時後備。未測實體手機 GPU。
- 額外試過：用「France」搜尋法國、鍵盤按 Enter 配合減少動態到香港、英文介面搜尋 `HK`，以及直接點擊屋內 3D 領巾、巾圈盒及徽章展示三件擺設。

## v0.5.0 · ROUND 1／2 · 屋主工作台

保留左邊可玩場景、右邊屋主設計；手機先見屋同三類展示，設定唔蓋住屋。1440、768、390 用 Chromium 截圖；望圖後縮窄欄位嘅收藏按鈕移除重複 icon，防止直排單字；色板三色同自訂揀色分開；拍照與揀檔同一列，預覽留在表單。最弱項：手機自訂項較多要捲動，內景只替章簿掛出本機相片預覽；其他類別相片在各自藏品頁。未做實機相機或 GPU 效能評分。

## v0.6.0 · 本機訪客預覽

維持原有屋內場景，將屋主日期同已確認社交連結置於訪客一入屋可見嘅位置；簽到係明確選做，而唔係阻住入屋。測 390／768／1440，中英切換後調整細屏導覽容許換行。核對警告預設聚焦返回、無聲簽到唔會發生、書籤持久化同隔離瀏覽器唔會見到本機資料。日期按瀏覽器時區，非實時在綫指示。
