# BadgeHouse · 徽章收藏屋

跟住小童軍由世界地圖去到收藏家嘅屋，揭章簿、睇領巾同巾圈，認識各地童軍藏品。

## 第一版 · v0.7.1（本機優先）

```sh
npm ci
npm run dev
npm run check && npm run build
node scripts/preflight_v1.0.mjs . --json
```

- **探屋**：3D 地球有 Scoutworld 五個區域、176 個成員地區，可按區域過濾或用中／英文、兩字代碼及組織名搜尋。每個地區都顯示旗幟同屋數；目前香港、日本、加拿大各有兩間示範屋，其餘 173 個地區顯示 0，照樣可以到訪。去到有屋嘅地區，角色先行到揀中嘅屋門，入屋再揀章簿、領巾牆或巾圈收藏盒。保留 2D 模式及直接連結。
- **認識當地童軍**：所有到訪頁（包括 0 間屋）都顯示童軍組織名同 WOSM 名錄，會徽同會旗分開。香港、日本、加拿大已接上會旗來源；其他待核實，唔以地區旗充當會旗。
- **我嘅屋**：屋名加屋主簡介，四款屋身、六款屋頂、十二套色板，亦可自己揀屋頂、外牆、門窗邊顏色。支援 3D／2D 預覽並儲存到此瀏覽器，未可公開發佈。
- **我嘅收藏**：章簿、領巾牆及巾圈收藏盒都可以新增、編輯、搜尋及分頁；直接拍照或選擇檔案，預覽後先儲存。相機只喺主動開啟時請求權限；不支援可用裝置拍照或揀檔。非 AI 純色退底保留。新版備份涵蓋三類藏品，仍可匯入舊章簿備份；屋設計同簡介唔包括喺藏品備份。
- **社交同到訪**：屋主自願填 HTTPS 社交連結，新加入或改動前會彈公開可見警告。已確認連結可喺訪客預覽睇到。示範屋和本機訪客預覽可加書籤。預覽訪客可以用暱稱或匿名簽到，屋主可查閱／清除；屋主最近返屋與屋資料最近更新分開顯示。呢幾樣暫時唔會跨裝置同步。

目前只係原型。示範屋唔係真實屋主；登入、跨裝置發佈、真實邀請／交換同檢舉待完成。未開付費資源。[原始產品大綱](readme)保留，最新確認以 [SCOPE](SCOPE.md) 為準。

## 部署第一版到 Vercel

匯入本倉，Production Branch 揀 `main`，Root Directory 留倉根目錄，Framework Preset 用 Vite。`vercel.json` 已指定 `npm ci --include=dev`、`npm run build` 同輸出 `dist`，**毋須設定環境變數或接駁資料庫**。`public/index.html` 由建置自動生成，唔需要上傳。

部署後用 HTTPS 開正式網址，試轉地球、入一間示範屋同開相機。部署只公開應用程式；屋主資料、收藏、書籤同訪客簿仍各自留喺瀏覽器。由原型預覽網址轉新網域時，舊瀏覽器資料唔會自動帶過去；三類藏品可先匯出備份，再喺正式網址匯入。屋設計同簡介未包含在備份內。
